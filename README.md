# Amazon-Sales-Data-Analysis-Data-Engineering
Data Analysis &amp; Engineering project on Amazon Sales dataset using Python &amp; Colab. Key techniques: EDA, Feature Engineering (Rating Credibility), PCA, and correlation analysis.

Collaborated on a team project to analyze a real-world Amazon Sales dataset using Python and Google Colab to uncover business insights and support data-driven decision-making.

The project involved collecting, cleaning, preprocessing, and analyzing real-world e-commerce data. We performed feature engineering, exploratory data analysis (EDA), correlation analysis, dimensionality reduction using PCA, and data visualization to identify meaningful patterns and trends.

We engineered a new feature called Rating Credibility to better evaluate the reliability of customer reviews. Correlation analysis identified a strong relationship between the original and discounted prices, leading us to remove the actual_price feature from the modeling dataset to reduce multicollinearity and eliminate redundant information.

Our analysis also revealed that customer ratings were not strongly influenced by product prices or discount percentages. Instead, Rating Credibility showed a stronger association with the number of customer reviews, providing valuable insights into customer behavior, pricing strategies, and product performance to support data-driven decision-making in e-commerce.

Technologies & Libraries: Python, Pandas, NumPy, Matplotlib, Scikit-learn, Google Colab, Kaggle.
